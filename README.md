# EasyMapWebsite

Site simple hébergé sur GitHub Pages, affichant une carte interactive créée avec [Folium](https://python-visualization.github.io/folium/) (Python) pour le TP "Cartes interactives sous Python" (R5.02 / SAE5.EMS.01, IUT SD).

Voir `index.md` pour la page d'accueil, et `ManausMap.html` pour la carte elle-même.
